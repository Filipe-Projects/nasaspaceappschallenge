    BeyondtheBlue

    SPHEREx returns to each patch of sky about every six months. BeyondtheBlue lines those visits up and plays them back, so anything that moved or changed brightness stands out.

    How it works
    1. Search. IRSA lists every SPHEREx image that covers the position.
    2. Cut out. Only the pixels around the target are read from each 70 MB file.
    3. Align and stack. Cutouts go onto one north-up grid and each visit is averaged per detector band.
    4. Compare. Every bright source is measured in every epoch; the ones that moved or varied are listed.
